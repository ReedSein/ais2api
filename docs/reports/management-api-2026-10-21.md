# 前端管理 API 与完整实时日志验证

日期：2026-10-21，Windows x64 / MSVC Release。本次为管理接口验收；测试账号、Cookie 和密钥均为合成数据，不新增 Google 生成能力的验收结论。

实现 `/api/admin/v1/`，由独立 `admin_key` 启用，覆盖账号导入、列表、元数据修改、启停、删除、首选切换、身份与邮箱探测，轮转与精确冷却清理，统计，模型缓存与异步发现，配置校验、持久保存与热更新/待重启状态，配置密钥轮换及独立多密钥 CRUD，服务状态、停止和脱敏诊断快照。原有 userscript 导入鉴权保持独立；旧数据库 keys 不会被重新授权。

管理日志写入持久 journal，并镜像到 stderr。专用写线程避免 HTTP reactor 等待 fsync；待写达到 256 时暂停 HTTP admission，继续保存已接收工作的日志，积压排空后恢复。持久化失败通过 `logging_healthy` 报告，已经完成的业务写入不会因日志失败被报成业务失败。

日志历史按游标完整分页，单批不超过 256 KiB，SSE 先补历史再每 200 ms 跟随更新，支持 Last-Event-ID 和显式游标续读。另提供服务、journal 及持久浏览器日志的完整原始字节读取/实时流（base64 分块），浏览器临时 profile 清理不会删除新浏览器日志。不存在固定最近 N 条截断；读取日志自身不生成无限反馈日志。目录与文件来源使用受控清单，拒绝通过源 ID 读取任意路径。
