# Debian 13 / WSL 2 本机适配记录

日期：2026-10-20。此报告记录本机离线及无账号浏览器验证；不代表 Ubuntu、
Termux 或真实 Google 生成验收。未导入真实 Cookie，也未调用 Google 生成接口。

## 环境及改动

- Debian GNU/Linux 13.5（trixie），x86_64，WSL 2。
- 内核 `6.18.33.2-microsoft-standard-WSL2`，glibc 2.41。
- GCC 14.2.0、CMake 3.31.6、Ninja 1.12.1、Node.js 20.19.2、Python 3.13.5。
- 额外使用 Clang 19 的 RelWithDebInfo 构建执行 ASan/UBSan 与 libFuzzer。
- vcpkg baseline `664933b8d385dfc01f4e0cdff4c7c74e71f6a740`；使用
  `x64-linux`，未改用未锁定的系统 C++ 依赖。
- 自动准备按 `/etc/os-release` 的精确 `ID` 与 `VERSION_ID` 接受 Debian 13，
  保留 Ubuntu 24.04 支持。两者使用 t64 浏览器运行库包名。
- 源码和依赖副本位于 Linux 文件系统的
  `$HOME/.cache/ais2api/debian13/`；只复制 Git 已跟踪的工作区文件，
  不复制 Windows 构建产物、参考项目或凭据。

WSL 默认继承 Windows PATH。五次不存在的程序查找在继承 PATH 下约需 2.023 秒，
仅 Linux PATH 下约需 0.010 秒。这是一次工具查找诊断，不是服务性能基准。
已完成的 16 项依赖缓存保留后，用仅 Linux PATH 续建；没有修改全局 WSL 或 shell 配置。

系统构建工具及浏览器运行库通过本机 `wsl.exe -d Debian -u root -- apt-get ...`
准备，只安装相关依赖及其包管理器依赖，没有执行系统整体升级。
自动准备使用 root 完成系统包步骤，随后仅将本次测试的 runtime 目录归属交还普通用户。
普通用户浏览器另通过原生 CDP 和实际 C++ BrowserGateway 测试，保持 Chromium 沙箱。
新增的 Debian 13 CI container job 仅做了 YAML 解析，尚未执行远程 CI，也不能代替 WSL 测试。

## 断连回归修复

Windows 回归最初暴露了取消测试失败。测试夹具原先在 `emit()` 后记录取消，
但信用等待期间的取消可让 `emit()` 提前抛出，造成漏记；已改为提前注册停止回调。
进一步用强制 RST 复现出生产问题：Windows Asio 的 `wait_read` 可能以错误完成，
原先 `!error` 条件忽略了该断连。现在仅忽略本地 `operation_aborted`。
正常关闭与强制 RST 两种场景重复 30 轮、共 60 次通过，未延长超时。

## 复现入口

普通 Linux checkout 的完整步骤见 [平台说明](../platforms.md)。本机使用的构建入口：

```sh
export PATH=/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin
export VCPKG_ROOT="$HOME/.cache/ais2api/debian13/vcpkg"
export VCPKG_MAX_CONCURRENCY=2
cd "$HOME/.cache/ais2api/debian13/source"
sh scripts/build.sh linux --package --jobs 2
```

本机保留了独立、无真实凭据的 runtime 配置，服务目前停止。进入 Debian 后可以查看：

```sh
root="$HOME/.cache/ais2api/debian13"
exe="$root/source/build/linux/install/bin/ais2api"
"$exe" --config "$root/runtime/config.json" --data-dir "$root/runtime/data" doctor
"$exe" --config "$root/runtime/config.json" --data-dir "$root/runtime/data" status
```

该配置尚未创建 API Key 或导入账号。后续先使用同一配置与数据路径执行 `init`，
保存首次显示的 API Key，再手动导入 Cookie。真实文本、多轮、流式、工具、媒体及
生图仍未验证；两小时稳定性和性能对照也不在此次结果中。
