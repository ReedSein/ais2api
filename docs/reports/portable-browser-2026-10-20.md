# 便携存储、并行下载与浏览器整合包

日期：2026-10-20。本机 Windows x64 / MSVC 与 WSL 2 Debian 13 x64 / GCC 14.2、Clang 19。真实 Google 账号验收按用户要求暂缓，以下结果均不代表模型生成已经通过。

## 存储行为

默认配置为可执行文件旁的 `config.json`，数据为同级 `data/`。浏览器下载、安装、资料目录及服务日志均放入该数据目录；浏览器子进程的 HOME、缓存及临时文件也限制到其私有资料目录。父进程环境不修改。相对配置路径按配置文件所在目录解析，显式指定的外部路径仍有效；已有绝对路径配置不会自动迁移。

Windows / Debian 各通过普通模式 31 项、内置浏览器模式 34 项便携检查，包括从不同工作目录启动、整体移动到含空格路径、密钥保留、服务关闭释放锁、用户目录和调用工作目录未新增文件。Linux 长路径实际浏览器及本地控制通道也已回归。Termux 尚未在设备上验证；系统包和 proot-distro 自身管理的容器位置遵循平台工具，不能由该测试证明全部系统文件位于程序目录。

## 下载

下载器对至少 4 MiB、支持字节范围且提供强 ETag 的资源使用最多四路分段。逐段验证状态、Content-Range 和资源标识，支持分段续传；不满足条件时退回单连接。最终长度及 SHA-256 仍必须匹配。TLS 校验保持开启，显式代理与环境代理均可使用。

本地 HTTPS、4 MiB 固定内容、每连接每 16 KiB 人工延迟 3 ms 的对照：

| 环境 | 单连接 | 四连接 | 观察到的比值 |
|---|---:|---:|---:|
| Windows | 3.17839 秒 | 0.890094 秒 | 3.57 |
| Debian | 1.32610 秒 | 0.219492 秒 | 6.04 |

这是用于验证并行传输行为的受控节流测试；调度、TLS 及服务端开销影响结果，不能推导真实互联网、GitHub CDN 或生成速度。下载专项测试为 7 用例、48 条断言，覆盖中断续传、忽略范围、资源变更、证书与摘要错误、大小限制。

## 测试与包

Windows 完整单元测试 80 用例 / 1,362 条断言；Debian 为 80 / 1,355。两端已安装 CLI 各 23 项通过，实际浏览器各 1 用例 / 8 条断言通过。Debian Clang ASan/UBSan 的完整单元测试和实际浏览器检查均通过。远端 CI、Ubuntu 实机和 Android 设备没有在本次运行。

已构建以下本地整合包，并验证 SHA-256 sidecar、全部浏览器文件清单及许可证，不包含配置、账号数据库、Cookie、日志或浏览器用户资料：

- Windows：`build/windows/packages/ais2api-0.1.0-Windows-AMD64-Browser-Local.zip`。
- Debian 13：`build/debian13/ais2api-0.1.0-Linux-x86_64-Browser-Local.tar.gz`。
