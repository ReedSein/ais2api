## Windows 开发回放记录

2026-10-20，Windows 11 Pro Insider Preview 10.0.29634 x64；AMD Ryzen AI 7 H 350（16 逻辑处理器），系统可见内存 32,630,636 KiB。MSVC 14.51、C++20、Release、静态运行库，依赖由根 vcpkg baseline 锁定。采集时工作区尚未初始化 Git，不能将这些历史测量回填绑定到之后的首次提交或某个已发布提交。

| 记录 | 负载 | 结果 |
|---|---|---|
| [未节流回放](windows-unpaced-120s.json) | 4 客户端持续新建短连接，无等待 | 120 秒，28,111 次尝试，15,857 成功，12,254 失败；不通过 |
| [有间隔回放](windows-paced-120s.json) | 4 客户端，每次完成后等待 100 ms | 120.104 秒，4,414/4,414 成功，零请求错误、零采样错误 |

未节流回放当时尚未采集错误分类，不能断言失败全部由某个原因造成。成功数接近 Windows 动态端口容量，短连接与 TIME_WAIT 是待验证的归因；该轮初期还并行运行了浏览器未登录冒烟测试，不能作为受控性能基线。后来为工具增加了错误分类及固定客户端间隔，没有修改系统 TCP 参数。两轮负载不同，**不能用它们计算加速倍数**。

有间隔回放 p50/p95/p99 约 5.36/7.54/10.11 ms，采用固定直方图，量化约 5%。其进程 RSS 首/末/采样峰值约 12.69/13.89/14.03 MB（十进制），队列采样峰值 1。生成工作线程累计 CPU 0.95 秒；包含 HTTP 客户端、服务和采样器的整个回放进程累计 CPU 24.97 秒。这些不是独立服务进程或浏览器的资源数据，也不是极限吞吐能力。

两个负载均使用合成生成源、真实 loopback HTTP/SSE、SQLite 及本地控制通道；没有实际模型生成，没有与原项目对照。两小时运行、慢客户端/大媒体/取消混合回放、浏览器资源测量和三端验收仍待完成。最终版本还加入了 HTTP 协程销毁时禁用唤醒回调的保护，由之后的完整自动测试验证；不应把这两份短测报告扩展解释为最终版本的长期稳定性资格。
